# ControlPrestamos — web informativa

Presentación, política de privacidad y condiciones de uso de la app Android.

Este repositorio contiene únicamente páginas públicas y su hoja de estilos.

## Publicar

En Settings → Pages, selecciona Deploy from a branch, rama main y carpeta /(root).
Guarda y espera a que GitHub muestre la URL del sitio. Comprueba estas rutas en una
ventana privada antes de usarlas en Google Cloud:

- Inicio previsto: https://JeremyCruzGallegos.github.io/controlprestamos-web/
- Privacidad prevista: https://JeremyCruzGallegos.github.io/controlprestamos-web/privacidad/
- Condiciones previstas: https://JeremyCruzGallegos.github.io/controlprestamos-web/condiciones/

Son rutas previstas; este paquete no confirma que el sitio esté publicado.
Si usas otro nombre de repositorio o un dominio propio, adapta las rutas de
404.html. Los enlaces del resto del sitio son relativos.

Publicar esta web no cambia el estado OAuth de la app ni acredita la propiedad
del dominio ante Google. Esa configuración se realiza en Google Auth Platform.
